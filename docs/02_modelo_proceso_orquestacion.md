# 02. Modelo de proceso y orquestación

**Versión:** 0.1  
**Estado:** arquitectura lógica preliminar

## 1. Objetivo

Definir cómo se mueve una persona por TravesíaHOMI sin fijar todavía un cronograma definitivo. Este documento describe estados, transiciones, reglas y excepciones. La parametrización concreta dependerá de competencias, nodos, lineamientos HOMI y capacidad de los ambientes.

## 2. Macroproceso

**Ingreso → caracterización → asignación de trayectoria → preparación → desarrollo de nodos → evidencia → evaluación → decisión → avance/refuerzo → práctica supervisada → confianza progresiva → transferencia → seguimiento**

## 3. Fases

### Fase 0. Activación
Se identifica persona, rol, servicio previsto, cohorte y fecha de ingreso. Se asigna la trayectoria pertinente y se explican reglas, responsabilidades y mecanismos de ayuda.

### Fase 1. Preparación inicial
Aproximadamente 8–9 días. Se intercalan nodos de múltiples competencias mediante estudio individual, trabajo grupal, simulación, campo, expertos y evaluación. No se plantea un día temático completo por competencia.

### Fase 2. Práctica clínica supervisada
Diez turnos. Los nodos se trasladan al desempeño real y se observan actividades profesionales relevantes. La supervisión puede variar según actividad, persona y contexto.

### Fase 3. Autonomía inicial acompañada
Seguimiento hasta aproximadamente el día 30. Disminuye la intensidad formativa, aumenta la observación de transferencia y se atienden brechas.

### Fase 4. Consolidación
Extensión a 60 días o más cuando sea pertinente.

## 4. Estados lógicos del participante por nodo

Un nodo puede recorrer, entre otros, los siguientes estados:

- ASIGNADO
- DISPONIBLE
- EN_PREPARACION
- EN_DESARROLLO
- PENDIENTE_EVIDENCIA
- EN_EVALUACION
- ALCANZADO
- REQUIERE_REFUERZO
- REINTENTO
- EN_TRANSFERENCIA
- CONSOLIDADO

No todos los nodos necesitan todos los estados.

## 5. Tipos de transición

- **Temporal:** se activa una ventana o momento.
- **Por cumplimiento:** se completa una actividad.
- **Por logro:** se alcanza un criterio.
- **Por dependencia:** un prerrequisito queda satisfecho.
- **Por riesgo:** se exige supervisión o simulación adicional.
- **Por excepción:** retraso, ausencia, reprobación o error.
- **Por oportunidad clínica:** aparece una experiencia real pertinente.
- **Por decisión de supervisión:** cambia el nivel permitido para una EPA.

## 6. Ruta prescrita vs. ruta ejecutada

### Ruta prescrita
Secuencia esperada de nodos, experiencias y condiciones.

### Ruta ejecutada
Trayectoria real vivida por la persona, incluyendo sustituciones de ambiente, retrasos, reintentos, oportunidades clínicas y refuerzos.

Ambas deben conservarse para análisis.

## 7. Gestión de grupos variables

El sistema no debe depender de que todos recorran el mismo lugar al mismo tiempo. Para grupos grandes:

- se dividen microgrupos;
- se utilizan ambientes equivalentes;
- se alternan experiencias individuales, grupales, simuladas y clínicas;
- se registran capacidades máximas por ambiente;
- se definen alternativas ante indisponibilidad;
- se realizan momentos de convergencia y socialización estructurada.

La estandarización se centra en las **experiencias mínimas y criterios**, no necesariamente en un recorrido físico idéntico.

## 8. Gestión por excepción

El proceso normal debe requerir baja intervención. La intervención humana se activa cuando existe:

- retraso relevante;
- evidencia ausente o insuficiente;
- criterio no alcanzado;
- repetición de errores;
- riesgo clínico;
- limitación de ambiente;
- necesidad de cambio de nivel de supervisión;
- situación no contemplada por el algoritmo.

## 9. Recuperación espaciada

Los nodos críticos pueden reaparecer mediante:

1. primera exposición;
2. recuperación a corto plazo;
3. aplicación en otra situación;
4. integración con otros nodos;
5. observación en servicio;
6. transferencia posterior.

La periodicidad será específica por nodo y riesgo.

## 10. Regla de madurez

Este modelo puede documentarse y probarse desde ahora, pero **no debe parametrizarse de forma definitiva** hasta validar competencias, nodos, lineamientos institucionales, experiencias y capacidad real de ambientes.
